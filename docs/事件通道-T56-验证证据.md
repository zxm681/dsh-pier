## 实施者决定（6 条）

1. `events` 仅布尔 true 启用；关闭时不公告能力，避免老安装行为变化。
2. 独立 `eventChannel.version=1` 而保留协议 v1；这是纯新增试验能力，不把 A2 尚未实现的语义说成 v2。
3. 每 link 每方向一个内部流；不提前做 E3 公共订阅/多消费者路由，防止不受限的流表。
4. 队列按整条 JSON-RPC UTF-8 行计字节、接收计入运行中的回调；字节/条数超限都可见，不把 socket 内核队列冒充有界事件队列。
5. 失步后终止该流增量、保留单个 gap，重订阅必须新纪元；不做隐藏重放或自动恢复，避免拿不完整镜像续写。
6. 50ms 在共享契约冻结给 E2；本轮不采集 VS Code 选区、不猜测文档 view key 或合并不同来源的业务事件。
