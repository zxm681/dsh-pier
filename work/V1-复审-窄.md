## 1. MF-01：逐出口核对与独立复现

### 源码路径

[save:1912–2020](<../packages/dsh-kit-bridge/src/capabilities.js#L1912-L2020>) 在 beginWrite 返回后立即进入 try，以下 throw 均经同一个 finally，区间内没有第二处收尾：

| 失败出口 | 位置 | 本轮实测首次错误 |
|---|---|---|
| saved:false | [1924–1942](<../packages/dsh-kit-bridge/src/capabilities.js#L1924-L1942>)；含 untitled 子分支也在 try 内 | -32603 / host-save-failed |
| 非布尔/畸形回执 | [1918–1922](<../packages/dsh-kit-bridge/src/capabilities.js#L1918-L1922>) | -32009 / field=saved；字符串、null、缺字段三种 |
| 写后路径复核异常 | [1946](<../packages/dsh-kit-bridge/src/capabilities.js#L1946>) | -32603 / path-changed-after-write |
| 写后文档身份检查异常 | [1947](<../packages/dsh-kit-bridge/src/capabilities.js#L1947>) | -32603 / document-identity-unavailable |

[唯一 finally:2016–2020](<../packages/dsh-kit-bridge/src/capabilities.js#L2016-L2020>) 调用 finishPolicyWrite，传 `{attribution: ATTRIBUTION.UNKNOWN}` 而不是 null。[finishPolicyWrite:1166–1172](<../packages/dsh-kit-bridge/src/capabilities.js#L1166-L1172>) 对实际 policy.endWrite 只调用一次；[endWrite:304–345](<../packages/dsh-kit-bridge/src/document-write-policy.js#L304-L345>) 先递减，在最后一个 holder 结束时显式 unknown 清 dirtyOwned，不清既有 taint。四个失败出口均不能抵达成功 return；成功 return 也经同一 finally。前置拒绝均在 beginWrite 之前，不应执行 endWrite。

注意 endWrite 的 Math.max 可掩盖重复扣减，因此自有探针直接包裹真实 endWrite 计数，不只断言最终 inflight=0；失败后重试仍要求累计 endWrite=1。另本轮全量门实际跑过[独立 holder 成功回归](<../packages/dsh-kit-bridge/test/t70-save-exit.test.js#L155-L165>)。

## 2. MF-02：默认 512 的独立容量探针

[默认值:125](<../packages/dsh-kit-bridge/src/document-write-policy.js#L125>) 为512；[stateFor:172–181](<../packages/dsh-kit-bridge/src/document-write-policy.js#L172-L181>) 遍历时跳过当前新条目、带 taint 或 inflight>0 的状态，仅删除其它条目。新条目保护也避免 markForeign/beginWrite 在返回后修改已脱离 Map 的孤儿对象。[endWrite:306–307](<../packages/dsh-kit-bridge/src/document-write-policy.js#L306-L307>) 每次只减一个 holder，尚有 holder 时不结算。

命令与 MF-01 相同，脚本中三次均为无参数 createWritePolicy()，没有 maxFiles 覆盖。[真实输出:7–10](<V1-narrow-probe.log#L7-L10>)：

```text
LRU default=512 taint pressure=600 evicted=89 allowed=false reason=foreign-change
LRU default=512 inflight pressure=600 evicted=89 holders=2->1->0 v2=inflight v3=foreign allowed=false
LRU default=512 allProtected=600/600 newHolder=1->0 evicted=0
PASS independent save cases=6 LRU cases=3; no real document/disk writes
```

分别证明：A 的 taint 经600个其它文件活动仍拒绝；A 两个 holder 经压力仍为2，窗口事件正常归类，逐次 end 后归零、撤销所有权，随后外来事件拒绝；600条全冻结记录逐一仍在且拒写，新 holder 也未被丢弃。前两组 evicted=89 证明真正跨越容量淘汰路径，不是未触发 LRU 的假绿。

**边界**：512 现在是软上限，受保护集合可超限保留；这是实现明确选择，不是“内存严格有界”的证明，不另开性能审查。
