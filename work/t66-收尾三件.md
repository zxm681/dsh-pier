### 1.2 `grant({windowId})` fail-closed（T64）

| 位置 | 内容 |
|---|---|
| [index.js:1859-1895](<../packages/dsh-vscode-kit/src/index.js#L1859-L1895>) | `grantEditing` 发放前：`boundWindow = _windowIdOf(link)`；`windowId` 给定时按 §3.1 口径解析；解析不到或解析到的**不是**承载连接 → `-32014 WINDOW_TARGET_FAILED`（`reason:'target-not-routable'`、`granted:false`、`boundWindow`/`targetWindow`/`resolveReason`） |

那种失败形态让人误以为是寻址 bug。

### 1.3 `establishBaseline` 接线 / `kit.editing.rebase`（T65）

| 位置 | 内容 |
|---|---|
| [index.js:1724](<../packages/dsh-vscode-kit/src/index.js#L1724>) | `async rebaseEditing(sessionId, confirmation, opts)`：本地四元形状门（file → version → incarnation → contentHash）→ 线上参数 `{file, expectedVersion, expectedIncarnation, contentHash, grant?}` → `this.request('vscode.rebaseBaseline', ...)` |
| [index.js:941](<../packages/dsh-vscode-kit/src/index.js#L941>)、[:2495](<../packages/dsh-vscode-kit/src/index.js#L2495>) | `this.editing.rebase` 与插件面 `editing.rebase`（未就绪 → `-32007`，不返回假成功） |
| [grant.js:112](<../packages/dsh-vscode-kit/src/grant.js#L112>) | `vscode.rebaseBaseline` 进 `WRITE_METHODS` ⇒ 自动获得 `_bindWriteTarget`（绑 grant）+ `_writeGate`（`-32010`）+ `assertLocalExpectedIncarnation` |
| [grant.js:773](<../packages/dsh-vscode-kit/src/grant.js#L773>) | `documentContentHash(text)`：CRLF→LF 后 sha256 小写 hex；**两侧共用这一份** |
| [capabilities.js:2538](<../packages/dsh-kit-bridge/src/capabilities.js#L2538>) | `rebaseBaseline(params, ctx)`：信任门 → 形状门 → 解析路径 → `serializeByPath` 串行 → 当次实测（`readDocumentState` + 整份 text）→ 四元比对 → `grantGate` 复核凭证 → `establishBaseline`；**不写盘** |
| [capabilities.js:65](<../packages/dsh-kit-bridge/src/capabilities.js#L65>) | `CAPABILITIES` 增 `'vscode.rebaseBaseline'`（现 11 项） |
| [document-write-policy.js:361](<../packages/dsh-kit-bridge/src/document-write-policy.js#L361>) | `establishBaseline(fileKey, info)` 重写：清 taint + `dirtyOwned = info.dirtyOwned === true`（**新增显式收养位**）+ 记 `baselineContentHash` |
| [whitelist.js:104](<../packages/dsh-vscode-kit/src/whitelist.js#L104>) | `METHOD_TIERS['vscode.rebaseBaseline'] = TIER_DELETE` |
| [response-contract.js:418](<../packages/dsh-vscode-kit/src/response-contract.js#L418>) | 回执契约：`ok/file/version/incarnation` + 不许出现 `applied`/`saved`/`quarantined`（不写盘就不许有写语义字段） |

三个必须说清的判断：

1. **为什么挂在写类清单上**：它不写盘，但它**能让被冻结的缓冲重新可写**——门在它这里就等于没有。
   挂上去之后 `-32010` 那道凭证门、会话一致性判、白名单 `delete` 档全都自动生效，没有第二条路。
2. **为什么 `establishBaseline` 要一个收养位**：判序 ⑥ 要求 `dirtyOwned === true` 才放行脏缓冲，
   而"人工确认过这份脏内容"正是 rebase 的语义。**只有这条控制面传 `dirtyOwned:true`**，
   ⑤（grant 的 `allowDirtySave`）仍然独立生效——两道门互不代偿。
3. **为什么锚点不符用 `-32602` 而不是 `-32011`**：`-32011` 的语义是"内容来源不可判、停在文件上"，
   而锚点不符是"你给的确认过期了，重读一遍再确认"，处置完全不同（后者可立即重试）。
